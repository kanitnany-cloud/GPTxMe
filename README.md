# AI x Kanitnan FPL Manager 2026/27

8-bit Fantasy Premier League dashboard for tracking the weekly decision process between Kanitnan and AI.

## What This Tracks

- Current FPL squad and starting XI
- Captain, vice-captain, bench order, and chip stance
- Weekly transfer radar and decision rules
- Mini-league strategy and rival watch points
- Top-rank trend notes
- Decision quality review after each Gameweek

## Current Theme

Cute 8-bit art dashboard, built as a single static `index.html` file for GitHub Pages.

## Weekly Story

This project is not only about points. It tracks whether each FPL decision was made with good information, clear reasoning, and the right risk level.
